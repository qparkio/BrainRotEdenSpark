## Твоя коллекция — чужая цель

По красной дорожке движутся брейнроты. Успей купить нужного, отправь его на базу и собирай доход. Пустые площадки постепенно превращаются в коллекцию, которую хочется показать всем. И которую кто-нибудь обязательно попытается унести.

Пробирайся на чужие базы, доставляй добычу домой и защищай собственных персонажей. Открывай новые этажи, инструменты и мутации. Проходи Rebirth ради постоянных бонусов. А когда начинается **Thunder**, арена становится песчаной, музыка меняется и в потоке чаще встречаются редкие персонажи.

**Покупай → зарабатывай → улучшай → кради → защищай → проходи Rebirth.**

## Что внутри

| Коллекция | Развитие | Соперничество |
| :--- | :--- | :--- |
| **56** воксельных персонажей | **3** этажа, **22** места на базе | Комнаты настроены на **до 8 игроков** |
| **8** редкостей: от Common до OG | **12** скинов базы | Кражи, перенос, оглушение и лазерная защита |
| Обычный вариант и **8** мутаций | **12** уровней Rebirth | Таблицы денег и завершённых краж |
| Index и слияние трёх персонажей | Пассивный доход и площадки сбора | **11** инструментов и чат комнаты |

- **База, которую хочется защищать.** Жёлтая площадка включает замок; закрываются и входы верхних этажей. Улучшения дают дополнительные места, а скины меняют оформление здания.
- **Инструменты для набегов и обороны.** Slap и его улучшения, катушки скорости и гравитации, ловушки, Bee Launcher, Taser, Cloak и Boogie Bomb.
- **Thunder.** Пятиминутная песчаная буря каждые тридцать минут серверного цикла: воронка, дюны, пыль, тёплый свет и отдельная музыка. Во время события увеличиваются веса появления Rare и более высоких редкостей.
- **Сохранение прогресса.** Сервер сохраняет профиль, открытия коллекции, инструменты, скины и счётчик завершённых краж.
- **Интерфейс с настоящими моделями.** Index, магазин, рюкзак, слияние и скины используют миниатюры игровых ассетов. Для общей громкости, музыки, эффектов и голосов предусмотрены отдельные настройки.

## Запуск

В репозитории находятся **исходный проект EdenSpark и его ассеты**. Для запуска нужен установленный EdenSpark.

Подготовка окружения для агента, подключение редактора по MCP и проверка первого запуска описаны в [AGENT_INSTALL.md](AGENT_INSTALL.md).

1. Установи [EdenSpark](https://edenspark.io/ru).
2. Склонируй репозиторий или выбери **Code → Download ZIP** и распакуй архив:

   ```sh
   git clone https://github.com/qparkio/BrainRotEdenSpark.git
   ```

3. Открой папку проекта в EdenSpark: в ней лежат `manifest.blk`, `main.das` и `main.prefab`. Если лаунчер использует отдельную папку локальных проектов, помести копию туда.
4. Нажми **Play** в редакторе, затем **PLAY** в игре. В лобби выбери **Play locally**.
5. Для локальной игры вдвоём открой второй клиент EdenSpark и присоединись к той же комнате.

Клиент запускается из `main.das`, выделенный сервер — из `dedicated.das`. Папку `assets/` и файлы `.meta` нужно сохранять вместе с исходниками.

## Управление

| Клавиши | Действие |
| :--- | :--- |
| **W A S D** | Движение |
| **Пробел** | Прыжок |
| **Зажать ПКМ и двигать мышь** | Поворот камеры |
| **Стрелки** | Поворот и наклон камеры |
| **Колесо мыши** | Приближение камеры |
| **E** | Купить, взаимодействовать, открыть продажу |
| **Удерживать E** | Украсть чужого брейнрота |
| **F / ЛКМ** | Применить выбранный инструмент |
| **1–9** | Выбрать слот инструмента |
| **B** | Рюкзак |
| **Enter** | Открыть чат / отправить сообщение |
| **Esc** | Закрыть игровое окно |

Чтобы забрать доход, наступи на площадку сбора. Чтобы закрыть базу, наступи на жёлтую площадку замка.

## Исходники

Клиент и сервер разделены между `main.das` и `dedicated.das`. Экономика и прогресс находятся в `server_game.das`, ростер — в `brainrot_data.das`, мир — в `world.das`, интерфейс — в `ui.das`. За Thunder отвечают модули `thunder_*.das`. В `tools/` находятся генераторы моделей, текстур и звуков, а также проверка ассетов.
